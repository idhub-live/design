# idhub.live
A single platform for technical guys to share their identitiy:
- Name
- Location, country, city
- SSH public key(s)
- digital business card
- Github profile
- Linked-in
- Phone number
- Whatsapp
- Email
- Website

## Roadmap
- users can sign-in using they're github account.
- every user has it's own page
- A command line interface to upload/sync SSH public keys from local machine
  to the `idhub.live` platform.
- A command line interface to update `idhub.live` profile.

## shell
idhub login
idhub upload
idhub profile update
